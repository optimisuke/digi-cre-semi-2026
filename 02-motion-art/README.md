## 進行メモ

- 冒頭・最後の事務局連絡は、それぞれ事務局が用意する別スライドで行います。

- 導入は10分。自己紹介はチャット中心にし、全員の口頭発表は必須にしません。
- 2つのお願いを続けて紹介し、好きなほうの生成を始めます。待ち時間に仕組みや動き・物語のヒントを説明します。
- 生成の速度には個人差があります。ひとつの作品をじっくりつくる参加も可。制作が長引いても14:55には事務局へ引き継ぎます。
- 共有の前に、自分で描いたイラストなどの画像を添付して、アニメーションにする方法も紹介します。
- 共有手順：Share →「Public: Anyone with the link can view」→ Copy link。コピーしたURLを会議のチャット欄に貼ります。見る人もGoogle AI Studioへのログインが必要です。
- 14:45から作品を共有し、14:52ごろから振り返りと次回予告へ。
- サンプルは静止画像です。動きの紹介は講師の作品画面で行います。
- 操作ガイドの画像は第1回と共通です。UIが変わっている場合は当日の画面で案内します。
- スライドは端末内のブラウザでも開けます。画像はローカル保存し、人物写真・操作ガイドは `../01-app/assets/` を参照しています。
