# ゲーム

- 日程：2026年10月20日（火）13:30–15:00
- 場所：オンライン
- 使用ツール：Google AI Studio の Build
- [スライドを開く](index.html)（全27ページ）

これまでと同じ「生成を始める → 待ち時間に説明 → ためす → 改良・自由制作 → 共有」の流れです。最初は事前案内のサンプルに合わせて、宇宙のシューティングゲームをつくります。後半はその改良か、別のゲームづくりを選べます。

初参加の人は画面付きの操作説明から、経験のある人は操作・ルール・難しさの工夫へ。最終回として、全3回の振り返りと、これからつくってみたいものを考える時間を設けます。

| 時間 | 内容 |
| --- | --- |
| 13:30–13:35 | 事務局連絡 |
| 13:35–13:45 | 前回の振り返り・自己紹介・準備 |
| 13:45–14:15 | ゲームをつくる・遊んでためす |
| 14:15–14:20 | 休憩 |
| 14:20–14:45 | 改良・自由制作 |
| 14:45–14:55 | 共有・全3回の振り返り |
| 14:55–15:00 | 事務局連絡 |

## 進行メモ

- 冒頭・最後の事務局連絡は、事務局が用意する別スライドで行います。この資料には連絡用ページを含めません。
- 導入は10分。自己紹介のお題はこれまでと共通です。人数に合わせて口頭での紹介を短くし、チャットも活用します。
- 最初のお願いはスライド10。生成中に、コードが動く仕組みとゲームの「操作・ルール・目標」を説明します。
- ゲームのサンプルは静止画像です。実際の遊び方は講師が生成した作品で紹介します。同じお願いでも結果は変わります。
- 最初は「始める・遊ぶ・もう一度」を確認。生成された操作説明に従い、使っている端末で操作できるかを確かめます。難しい場合は画面のボタン追加などをお願いします。
- 前回参加者は動きの工夫から一歩進め、難しさや操作しやすさを調整。初参加者はまず1回遊べればOKです。
- 休憩スライドは「5分後に再開します」と案内します。
- 自由制作は今のゲームの改良でも、新しい作品でもOK。ひとつ変更して遊び直し、違いを確かめます。
- 14:45から共有、14:52ごろから全3回の振り返りへ。14:55には事務局に引き継ぎます。
- 操作ガイドは第1回の画面です。UIが変わっている場合は当日の画面で案内します。
- HTMLをブラウザで開けば利用できます。人物写真・操作ガイドは `../01-app/assets/`、前回の作品画像は `../02-motion-art/assets/` を参照します。

## 最初のお願い

> 宇宙を舞台にしたシューティングゲームを作って。左右キーや画面のボタンで機体を動かせて、弾は自動で発射。かっこよくして。
