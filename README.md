## スライドの開き方

[全3回の案内](index.html) または [第1回のスライド](01-app/index.html) をブラウザで開きます。インストールやビルドは不要で、スライド表示には外部ライブラリ・外部フォント・ネット接続を必要としません。Google AI Studioの利用にはネット接続が必要です。

- 16:9のスライドを画面サイズに合わせて表示します。
- 画面下の「←」「→」、または左右の矢印キーでページを送れます。
- Space / PageDown は次へ、Shift + Space / PageUp は前へ、Home / End は最初／最後へ移動します。
- セレクトボックスからページを直接選べます。
- `01-app/index.html#3` のようにページ番号を指定できます。
- 対応ブラウザでは「全画面」ボタンを利用できます。
- ボタンやセレクトボックスにフォーカスがある間は、その要素本来のキー操作を優先します。

## 現在の内容と編集方法

第1回は全18枚。Buildにチャットで指示して、自分専用のアプリをつくる体験です。まず全員が短い指示でToDoアプリをつくり、追加・完了の動作をためします。その後は「ToDoをもっとよくする」「別の好きなアプリに挑戦する」のどちらかを選んで自由制作に進みます。冒頭の10分には、普段使っているAIをWeb会議のチャットに書くアイスブレイク（2〜3分）を含めます。最後はアプリの画面キャプチャとひとことをチャットに投稿して見せ合います。講師と一緒に短い指示を入力する時間は5分（13:40–13:45）、ToDoを動かして制作を続ける時間は20分（13:45–14:05）、休憩は5分（14:05–14:10）、選んでつくる自由制作は35分（14:10–14:45）です。一緒に試すスライドにBuildへのリンクと2行の指示例をまとめています。制作例と90分の進行案はたたき台です。第2回・第3回はフォルダのみ準備し、スライドはまだ作成していません。

今回の体験は、データの長期保存や一般公開を前提にしない試作を中心にします。入力データの保存は実装に依存し、画面を閉じたり再読み込みしたりすると消える場合があります。共有・公開には別途設定や利用条件の確認が必要です。Build自体に保存・公開機能がない、という意味ではありません。

`01-app/index.html` 内の `<section class="slide">` が1ページです。セクションを追加・削除すると、ページ数と選択メニューが自動で更新されます。各ページの見出しIDと `aria-labelledby` は一致させ、IDが重複しないようにしてください。CSSとJavaScriptも同じファイルにまとめています。

デザインは [Good Job! Center](https://goodjobcenter.com/) の生成り色（`#FCF7F3`）と黒を基調にした配色を参考に、余白・大きな見出し・幾何学図形で構成しました。サイトのロゴや写真は使用していません。
