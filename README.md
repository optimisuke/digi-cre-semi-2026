# デジクリゼミ 2026 — AIを活用した創作

「障害のある人と学ぶデジクリゼミ」体験入門コースの資料です。
Google AI StudioのBuildで、自分たちのためのアプリや作品をつくります。

**[公開スライド・全3回の案内](https://optimisuke.github.io/digi-cre-semi-2026/)**

| 日程 | テーマ | 資料 |
| --- | --- | --- |
| 9/29（火） | アプリ | [第1回](01-app/index.html) |
| 10/6（火） | モーションアート／アニメ | [第2回](02-motion-art/index.html) |
| 10/20（火） | ゲーム | [第3回](03-game/index.html) |

2026年、各回13:30–15:00・オンライン。
ネットにつながる端末とGoogleアカウントを用意してください。

第1回は、まずToDoアプリの生成を始め、待ち時間に説明を進めます。できたアプリを試したあと、改良か別アプリへの挑戦を選びます。

第2回は、魚の群れのモーションアートか、宇宙に行く猫のアニメを選んでつくります。どちらかひとつでOK、余裕があれば両方に挑戦。前回の振り返りや仕組みの説明をはさみ、後半は改良・自由制作と作品共有を行います。冒頭と最後の各5分は事務局連絡です。

**[第2回の公開スライド](https://optimisuke.github.io/digi-cre-semi-2026/02-motion-art/)** / [進行メモ](02-motion-art/README.md)

第3回は、宇宙のシューティングゲームをつくり、遊んで確かめます。後半は改良か別のゲームづくりを選び、操作・ルール・難しさを自分好みに。最後に全3回を振り返ります。

[第3回のスライド](03-game/index.html) / [進行メモ](03-game/README.md)

## 開く・編集する

各回の `index.html` をブラウザで開き、矢印キーまたは画面下のボタンでページを送ります。ビルド不要。
`<section class="slide">` が1ページで、画像は各回の `assets/` に保存しています。
